Integration tests require a disposable Redis instance containing only synthetic test data. Set GO_REDIS_TEST_ADDR to its explicit loopback host and port before running go test -race ./.... The test entry point rejects a missing address or a non-loopback host. Tests and examples use this address; they never fall back to localhost:6379. Existing tests use fixed keys and may delete those keys, so do not point this command at a shared or production Redis service.
